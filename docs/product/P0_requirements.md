1. Web App initially, potentially support mobile app
2. When user log in, by default, they see the calendar view of the current month
3. User have the capability to select a year and month and view the corresponding calendar.
4. Each date on the calendar will be represented by one image of that date.
5. User can click on a specific date, and view all the images of that date.
6. User can select a date (by default today) and upload any images, and add tags, locations, descriptions for the images.
7. The images uploaded by the user should be persisted.
8. User can share the calendar with other users.
9. This is in POC stage, so make sure to use to design with frugality in mind.
10. User can see their calendar as well as anyone else's calendar shared with them.
